# Deployment

The production site is hosted on Vercel and uses Cloudflare R2 for media storage.

The `udsfgecw/website` GitHub repository is connected to Vercel. Pushing to `main` triggers a Vercel deployment; the Vercel commit status reports when it finishes. Production URL: <https://www.udsfgecw.in>.

GitHub Pages is not used for production. Its workflow has been removed from this repository.
